How to Import a Valorant Crosshair Code

  1. Copy the crosshair code.
  2. Open Valorant and go to Settings → Crosshair.
  3. Use the crosshair import option and paste the code.
  4. Save/select the profile and test it in the Practice Range.

A popular player's crosshair is only a starting point. Choose a color, size and spacing that stays visible and comfortable for your own aim.
