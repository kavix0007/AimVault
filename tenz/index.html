How to import this crosshair

  1. Copy the crosshair code above with the Copy code button.
  2. Launch Valorant and open Settings from the menu in the top-right corner.
  3. Go to the Crosshair tab.
  4. Next to Crosshair Profile, choose the Import Profile Code option.
  5. Paste the code and confirm. The crosshair updates instantly in the preview.
  6. Optional: save it to an empty profile slot so you can switch back to your old crosshair at any time.

A full walkthrough with screenshots is in the guide to importing Valorant crosshair codes.
