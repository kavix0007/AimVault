How to Import a Valorant Crosshair Code

VALORANT supports crosshair profile import/export. Use the Crosshair settings import control, paste the copied profile code, import it, and test the result in-game. Riot Games Patch 4.05 notes describe the feature.

Quick steps

  1. Copy a code from AimVault.
  2. Open VALORANT → Settings → Crosshair.
  3. Use the crosshair profile import control.
  4. Paste and import the code.
  5. Test the imported profile in-game.
