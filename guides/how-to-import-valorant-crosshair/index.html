How to Import a Valorant Crosshair Code

VALORANT supports crosshair profile import/export. Use the Crosshair settings profile import control, paste the code and check the result in-game.

Steps

  1. Copy an AimVault code.
  2. Open VALORANT and go to Settings → Crosshair.
  3. Use the profile import control.
  4. Paste the code and import it.
  5. Check the result in-game.
