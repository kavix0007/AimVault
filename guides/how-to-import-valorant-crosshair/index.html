How to Import a Valorant Crosshair Code

Every crosshair code on AimVault can be pasted directly into Valorant. It takes under a minute.

  1. 1

    Copy a code

    Find a crosshair on AimVault and press "Copy code" on its card. The code is now on your clipboard.

  2. 2

    Open Settings in Valorant

    From the main menu, open Settings, then go to the Crosshair tab.

  3. 3

    Find Import Profile Code

    Scroll to the bottom of the Crosshair tab. There's a field labeled "Import Profile Code".

  4. 4

    Paste and confirm

    Paste the copied code into that field and press Enter. Your crosshair updates immediately in the preview.

If the code doesn't apply

Make sure nothing extra was copied along with the code — no leading or trailing spaces, and no line breaks. Codes always start with 0;, so if what you pasted looks different, copy it again from the card rather than typing it by hand.
